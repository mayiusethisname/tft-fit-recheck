TFT 측정 파일을 놓으면 이동도를 계산합니다.

이동도는 그래프에 그은 직선의 기울기로 구합니다. 그런데 직선을 어느 구간에 긋느냐에 따라 기울기가 달라집니다. 같은 측정에서 구간만 바꿔도 이동도가 20배까지 달라집니다. 구간을 직접 옮겨 보세요.

측정 파일

그래프로 끌어다 놓거나 누르세요.

파일은 이 브라우저 안에서만 읽습니다.

이동도 μ
문턱전압 Vth
R²
쓴 점

시작 구간은 측정 범위의 가운데 3분의 1입니다.

계산 방법

  1. 전류의 제곱근을 전압에 대해 그립니다. 소자가 켜진 뒤에는 직선에 가까워집니다.√|I| = a·V + b
  2. 고른 구간에 직선을 맞춥니다. 기울기 a가 이동도를 정합니다.μ = 2·L·a² / (C·W)
  3. 직선이 전압 축과 만나는 점이 문턱전압입니다.Vth = −b / a

W, L은 채널 폭과 길이, C는 절연막 용량(1.75×10⁻⁸ F/cm²)입니다.

만든 이유

수업의 측정 파일은 DAT와 CSV가 섞여 있어, 형식마다 그래프 매크로를 따로 짜야 했습니다. 직선 구간은 사람이 눈으로 골랐습니다. 파일을 놓기만 하면 그래프가 나오고, 구간에 따른 차이를 한눈에 볼 수 있게 만들었습니다.

다음에 더할 것

  • 구간 제안. 이동도가 가장 덜 변하는 구간을 찾아 먼저 보여 주기.
  • 다른 장비의 파일. 열 이름이 다른 측정 파일도 읽기.

배운 것

  • 잘 맞는 것과 맞는 값은 다릅니다. 직선이 깔끔하게 맞아도, 구간을 옮기면 값이 달라졌습니다. 결과 하나를 믿기 전에 조건을 바꿔 다시 계산합니다.
  • 계산보다 입력이 먼저입니다. 원본 숫자가 그대로 들어왔는지부터 확인합니다.
  • 반복되는 손작업은 도구로 바꿉니다. 형식 차이를 없애자, 비교에 쓸 시간이 생겼습니다.
