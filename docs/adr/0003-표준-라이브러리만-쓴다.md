# 0003. 파이썬 표준 라이브러리만 쓴다

- 날짜: 2026-11-13
- 상태: "자바스크립트를 쓰지 않는다"는 2026-11-14 adr/0004로 바뀜. 나머지는 그대로 (AI 제안, 2026-11-14 설계 승인과 함께 사용자 수락)

## 배경

계산은 직선 맞춤 하나이고, 사이트는 고정 페이지 한 장이다. 사용자가 모든 코드를 면접에서 설명할 수 있어야 한다.

## 결정

- 계산: 표준 라이브러리만 쓴다. 직선 맞춤은 식을 직접 쓴다(평균, 합, 나눗셈).
- 그림: SVG 글자를 파이썬이 직접 쓴다. 그래프 라이브러리를 쓰지 않는다.
- 사이트: 파이썬이 HTML 파일을 만든다. 자바스크립트를 쓰지 않는다.
- 테스트: 표준 라이브러리 `unittest`.

## 버린 선택지

- numpy, matplotlib: 코드는 짧아지지만 "이 함수가 안에서 무엇을 하는가"를 설명할 수 없는 부분이 생긴다. 직선 맞춤 식은 다섯 줄이라 직접 쓰는 편이 설명하기 쉽다.
- 자바스크립트로 결과 파일을 읽어 그리는 화면: 기존 도구가 이 방식이었고 화면 코드가 전체의 절반을 넘었다.

## 결과

- 설치할 것이 없다. `python -m recheck build` 한 번으로 전부 다시 만든다.
- 그림이 단순해진다(막대, 선, 점). 확대나 겹쳐 보기는 없다.
- 나중에 그림이 복잡해져 직접 쓰기 어려워지면 그때 이 결정을 다시 본다.
