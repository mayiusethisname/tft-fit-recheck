# 0001. 원자료는 공개 레포에 올리지 않는다

- 날짜: 2026-11-13
- 상태: 결정됨 (사용자). 2026-11-14 adr/0004로 예외 하나가 생김(이미 공개된 9개 소자의 이동도 측정)

## 배경

TFT 원자료는 수업(AMD 실험)에서 여러 해 누적된 측정 파일이다. 파일 안의 측정 날짜가 2013-05-28, 2022-02-14로 사용자가 직접 측정한 것이 아니다. 공개해도 되는지 허락을 받은 적이 없다.

## 선택지

- A. 담당자에게 묻고, 답이 올 때까지 비공개 (AI 추천)
- B. 원자료는 올리지 않고 계산 결과와 그래프만 공개 (사용자 선택)
- C. 기존처럼 발췌본을 공개

## 결정

B. 원자료와 발췌본은 새 레포에 넣지 않는다. 사용자 PC의 `D:\AMD\8주차`에서 읽어 계산하고, 결과(표·그래프)만 레포에 둔다.

## 결과

- 다른 사람이 레포만 받아서는 수치를 다시 계산할 수 없다. 대신 "어떤 파일에서 어떤 명령으로 나온 값인지"를 결과와 함께 적는다.
- 사이트는 방문자가 올린 파일을 분석하는 방식이 아니라, 미리 계산한 결과를 보여 주는 방식이 자연스럽다.
- 남은 위험: 기존 공개 레포에는 발췌본이 이미 올라가 있다. 기존 레포는 건드리지 않기로 했으므로 이 상태는 그대로다.
