# 0004. 사이트를 파일을 끌어다 놓는 도구로 바꾼다

- 날짜: 2026-11-14
- 상태: 결정됨 (사용자). 0001·0002·0003의 일부를 바꾼다

## 배경

5단계에서 만든 페이지(숫자 하나, 막대 그림, 검수 기준표)를 본 사용자가 "자동화 그래프 페이지가 아니라 무슨 노트"라며 거절했다. 인터뷰 2라운드에서 AI가 "도구가 아니라 기준표, 고정 페이지"를 추천했고 사용자는 "추천대로"라고 했지만, 완성된 모습을 그림으로 본 적이 없어 무엇을 승인하는지 알지 못했다.

## 결정 (모두 사용자 선택)

1. 사이트는 파일을 놓으면 그래프와 이동도가 나오는 도구다. 첫 화면에 대표 그래프 하나를 띄워 둔다.
2. 재료와 W/L만 적은 파일 아이콘을 띄워 두고, 그래프로 끌어다 놓으면 적용된다.
3. 계산은 방문자 브라우저의 자바스크립트가 한다. 서버는 없다.
4. 아이콘으로 올리는 자료는 **기존 사이트(`tft-tauc-data-review.vercel.app`)가 이미 공개 중인 9개 소자**의 이동도 측정(전압·전류 201쌍)뿐이다.

## 버린 선택지

- 15개 소자 모두 올리기: 6개가 처음 공개된다. 수업 자료를 올려도 되는지 확인할 방법이 없다.
- 측정 숫자는 올리지 않고 미리 그린 그림만 바꾸기: 방문자가 구간을 옮겨 다시 계산할 수 없다.
- 서버에서 파이썬으로 계산: 파이썬 한 벌로 끝나지만 서버와 입력 처리가 다시 생긴다.

## 앞선 결정에서 바뀌는 것

- **0001**: "측정값은 내보내지 않는다"에 예외가 생긴다. 9개 소자의 이동도 측정은 올린다. 원본 파일, 다른 측정(HIGHTRANS 등), UV–Vis 자료, 나머지 6개 소자는 여전히 올리지 않는다.
- **0002**: "고정 페이지, 업로드 없음"을 버린다. "TFT만, Tauc는 사례 한 건"은 그대로다.
- **0003**: "자바스크립트를 쓰지 않는다"를 버린다. 라이브러리를 쓰지 않는다는 것은 그대로다(파이썬도, 자바스크립트도).
- 과제 조건 "언어는 파이썬": 계산식이 자바스크립트로도 한 벌 더 생긴다. 사용자가 차이를 듣고 골랐다.

## 결과

- 면접에서 설명할 코드가 두 언어다. 같은 식을 같은 이름으로 쓰고, 페이지가 열릴 때 두 계산이 일치하는지 비교해 화면에 적는다.
- 9개 소자의 숫자는 누구나 사이트에서 꺼낼 수 있다. 기존 사이트에서 이미 그랬으므로 새로 드러나는 자료는 없다. (AI가 기존 레포의 `samples/` 폴더를 보고 한 말이다. 6단계에서 9개가 같은 소자인지 다시 대조한다)
- 방문자가 놓은 파일은 브라우저 안에서만 읽는다. 어디로도 보내지 않는다.
