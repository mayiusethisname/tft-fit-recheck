# 0002. 사이트는 고정 페이지, 분석은 TFT 중심

- 날짜: 2026-11-13
- 상태: 1번(고정 페이지)은 2026-11-14 adr/0004로 바뀜. 2번(TFT 중심)은 그대로 (AI 추천을 사용자가 수락)

## 배경

원자료를 공개하지 않기로 했다(0001). 볼 사람은 채용 담당자와 현업 엔지니어이고, 대표 산출물은 도구가 아니라 검수 기준표다.

## 결정

1. 사이트는 미리 계산한 결과를 보여 주는 고정 페이지다. 방문자가 파일을 올려 분석하는 기능은 만들지 않는다. 계산은 사용자 PC에서 파이썬으로 하고, 표와 그림을 파일로 저장해 올린다.
2. 분석은 TFT(포화 이동도, 문턱전압)만 구현한다. Tauc(밴드갭)는 "이 자료로는 구할 수 없다는 것을 확인한 사례" 한 건으로만 남긴다.

## 버린 선택지

- 업로드 분석 유지: 입력 처리 코드 약 650줄이 다시 필요하고, 공개 샘플이 없어 방문자가 넣어 볼 파일도 없다.
- Tauc까지 구현: 박막 두께, 굴절률, 유리 기판 흡수 등 출처를 모르는 조건이 많아 면접에서 설명할 수 없는 부분이 늘어난다.
- Tauc 완전 제외: "AI는 구할 수 없는 값도 구해 준다"는 좋은 사례를 잃는다.

## 결과

- 서버가 없다. 기존 도구의 업로드, 입력 경계, 화면 조작 코드는 가져오지 않는다.
- 그래프에도 측정점이 드러나므로 곡선 전체가 아니라 필요한 그림만 올린다.
